# Scan Sorter

A simple GTK application for visually sorting scanned photographs and slides.

Scan Sorter is intended for collections of scanned images where the original
ordering has been lost or needs to be corrected. Images can be arranged
visually and then renamed into the chosen sequence.

## Status

Early development.

## Requirements

- Python 3.11 or later
- GTK 4
- PyGObject

## Development

The application is currently developed and tested on Linux using Python and
GTK 4.
